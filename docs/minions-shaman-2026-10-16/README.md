## 1. สมุนผีลงสนามแล้วทำทันที

**ปัญหา:** สมุนผี 12 ตัวมีเลือด 5–10 บังหมัดเดี่ยว (taunt) และทำงานครั้งเดียวตอนท้ายเทิร์นผี (ตี 2 / พิษ 1 / เกราะ 3) การ์ดเราใบเดียวฆ่าได้ จึงมักตายก่อนได้ทำอะไร

**ที่ตกลง:** สมุนผีทุกตัวมีผล `arrive` ทำครั้งเดียวทันทีที่ลงสนาม ไม่มีนับถอยหลัง ยังตีได้และตายง่ายเหมือนเดิม ยังเรียกผ่านการ์ดในมือผี (ผีเลือกจังหวะเอง) เรียกซ้อนได้ 3 ตัว เต็มแล้วตัวเก่าสุดถอยออก (กติกาเดิม) ท่าท้ายเทิร์นเดิมยังอยู่ เป็นโบนัสถ้าผู้เล่นไม่ฆ่า

**ที่ไม่ทำและเหตุผล:**
- นับถอยหลังแล้วหาย — สมุนตายก่อนครบเวลาเกือบทุกครั้ง ไม่แก้ปัญหา (เจ้าของตัดออก)
- "อยู่นานยิ่งอันตราย" — ใช้ไม่ได้ด้วยเหตุผลเดียวกัน
- เพิ่มเลือดสมุน — เจ้าของไม่ต้องการ
- สมุนที่โดนแค่ท่ากวาด ("วิญญาณลอย") — พักไว้ ถ้าลองให้เป็นท่าประจำผี 1–2 ตัว ไม่ใช่ระบบทั้งเกม

ผลตอนลงใช้เฉพาะเอฟเฟกต์ที่ระบบผีรองรับอยู่แล้ว (`applyEnemyFx`) ดาเมจจากสมุนไม่ผ่านนักมวยรุ่นพี่ (กติกาเดิมของสมุน) ศิษย์ค่ายฝั่งเราไม่มี `arrive`

**AI:** `enemySummonValue` บวกค่าผลตอนลงให้เฉพาะตัวที่เพิ่งเรียก (ตัวที่ถูกดันออกลงมาแล้ว ไม่นับซ้ำ) ปัดเกราะมีค่าเท่าเกราะที่เรามีจริง ข้อจำกัด: ดาเมจตอนลงไม่ได้จำลองบนกระดานคิดของ AI จึงไม่ใช้เป็นเหตุผลเลือกเส้นฆ่า (เป็น heuristic ไม่ใช่การค้นหาสมบูรณ์)

**ผลซิม (นักมวย ซึ่งไม่โดนข้อ 2):** รวมสอง seed อัตราชนะ d1 85 → 80, d3 75 → 70, d4 49 → 46, d5 22 → 19 ยากขึ้นเล็กน้อยตามตั้งใจ (อยู่ในช่วงคลาดเคลื่อนของแต่ละช่อง แต่ทิศเดียวกันทุกระดับ) ไม่มีเกมค้าง

## 2. หมอผีเริ่มไฟต์น้ำมนต์ 2 (เดิม 4)

**ปัญหา:** เทิร์นแรกหมอผีมีน้ำ 4 + นั่งสมาธิ +3 = 7 แล้วสาดน้ำมนต์ (5 ต่อน้ำ) ได้ 35 ผีคืนแรกเลือดราว 22–30 จึงตายในเทิร์นเดียว ซิมยืนยัน: ไฟต์ผีธรรมดาคืน 1 ของหมอผีจบใน 2.6–2.7 เทิร์นและได้เลือดคืนสุทธิ ขณะที่นักมวยใช้ 3.8 เทิร์น

**ทำไมแก้ตรงนี้:** เป็นต้นเหตุโดยตรงของการระเบิดเทิร์นแรก น้ำต่อเทิร์น (+3) และขัน (12) ไม่เปลี่ยน ไม่แตะผีคืนแรก เพราะนักมวยคืนแรกลำบากอยู่แล้ว (d5 ตายคืนแรก 31/60)

**ทำไม 2 ไม่ใช่ 1:** ทดลองทั้งสองค่าบน 2 seed (รวม 120 รอบ/ช่อง)
- น้ำเริ่ม 2: อัตราชนะหมอผีรวมสอง seed d1 82 / d2 65 / d3 73 / d4 58 / d5 16 — ใกล้นักมวย (80 / 68 / 70 / 46 / 19) และยากกว่า main (89 / 74 / 79 / 65 / 15)
- น้ำเริ่ม 1: d1 77 / d2 67 / d3 72 / d4 53 / d5 12 — ต่ำกว่านักมวยเกือบทุกระดับ และ d5 ต่ำสุด จึงถือว่าเกินเป้า

เทิร์นแรกสาดสูงสุด 25 (เดิม 35) ถ้าเล่นบนมือถือแล้วคืนแรกยังง่าย ขั้นถัดไปคือ 1

**ข้อจำกัด:** บอทถือการ์ดสาดจนน้ำ ≥5 แต่คนสาดตั้งแต่เทิร์นแรก ผลต่อคนจริงน่าจะชัดกว่าตัวเลขบอท ต้องเล่นบนมือถือยืนยัน ระดับ/พร/สกิลที่เพิ่ม `startMana` ยังบวกจากฐานใหม่ตามเดิม ผลซิมของ "น้ำเริ่ม 2/1" รันบน commit ที่มีการทดลองมือผี (ข้อ 3) ซึ่งพิสูจน์แล้วว่าไม่เปลี่ยนผลแม้แต่รอบเดียว จึงเทียบได้ตรง

## 3. มือผีโตตามคืน — ทดลองแล้ว ยังไม่ใส่ (รอเจ้าของตัดสิน)

**แนวคิดที่คุยกัน:** ผีคืน 2–3 ถือไพ่ได้มากขึ้น ให้รู้สึกว่า "ฉลาดขึ้น" ไม่ใช่แค่ตีแรงขึ้น

**สิ่งที่พบ:** เพิ่มขนาดมือ +1 และเก็บข้ามเทิร์น +1 ในคืน 2–3 แล้ว ผลซิม **เหมือนเดิมทุกตัวเลข** วัดจริงพบว่าท้ายเทิร์นผีเหลือไพ่ในมือ 0–1 ใบเกือบทุกครั้ง (คืน 3: 117 จาก 129 ครั้งเหลือ 0 ไม่เคยเหลือเกิน 2) เพราะการ์ดโจมตีเล่นฟรี ผีจึงเทมือทิ้งทุกเทิร์น เพดานมือ/เก็บไม่เคยถูกใช้ จึงถอดออกจาก branch

**ในเกมนี้ "มือใหญ่ขึ้น" มีผลก็ต่อเมื่อผีจั่วมากขึ้น** ซึ่งแปลว่าผีเล่นการ์ดมากขึ้นต่อเทิร์นด้วย ไม่ใช่แค่มีทางเลือกมากขึ้น

**ทดลองทางเลือก (ไม่ได้ใส่):** ผีธรรมดาคืน 3 จั่ว +1 (จาก 2 เป็น 3) seed `claude-audit` 60 รอบ/ช่อง

| | ก่อน | ผีธรรมดาคืน 3 จั่ว +1 |
|---|---|---|
| ไฟต์ผีธรรมดาคืน 3 นักมวย | 3.04 เทิร์น, ได้เลือดคืน 3.1 | 3.15 เทิร์น, เสียเลือด 0.1 |
| ไฟต์ผีธรรมดาคืน 3 หมอผี | 3.04 เทิร์น, ได้เลือดคืน 2.5 | 3.16 เทิร์น, เสียเลือด 1.7 |
| อัตราชนะ | — | ลดลง 0–10 จุด (นักมวย d1–3, หมอผี d2–4) |

ตอนนี้ผีธรรมดาคืน 3 อ่อนจนผู้เล่นออกจากไฟต์พร้อมเลือดมากกว่าตอนเข้า การจั่ว +1 ทำให้ไฟต์พวกนี้มีราคาจริง แต่เป็นความยากแบบ "กดดันมากขึ้น" ไม่ใช่ "ฉลาดขึ้น" เจ้าของต้องเลือกว่าจะเอาไหม ถ้าเอา ใส่ใน `drawEnemyHand` ข้าง `ENEMY_DRAW_CADENCE` และเพิ่มคำอธิบายใน UI มือผี (`MonsterArea`)
