## การทำงานและการทดสอบ

ข้อมูลหมอผีสร้างซ้ำด้วย `python3 scripts/mor-phi-data.py` และ manifest ภาพด้วย `python3 scripts/mor-phi-art.py`. ภาพเดิมและ starter deck เดิมไม่เปลี่ยน คำอธิบายนักมวยเรียกสมุนว่า “ศิษย์ค่าย” ส่วนหมอผียังใช้ “ของเลี้ยง”

ชุดทดสอบใหม่ใช้การเล่นและแก้ผลจริง: เงื่อนไขต่อท่า/ช้ำ/ยก, น้ำ/ยันต์/เลือด/สมุน, สำรับครบทุกตัว, ชาร์จ/คงมือ/สำเนาการ์ด, ลำดับโจมตีใส่ตัวรับแทน, การเปลี่ยนสมุน และอุปกรณ์กันตาย/จำกัดดาเมจ โดยตรวจ deterministic และไม่แอบอ่านข้อมูลผู้เล่นด้วย ผลสุดท้ายผ่าน 49 ไฟล์ / 681 tests, TypeScript และ Web export; เก็บหลักฐานซิม 6,600 รัน รวมชุดตรวจอิสระเทียบ main รายละเอียดข้อจำกัดเรื่องระดับยากและการตรวจหน้าจอมือถืออยู่ใน BALANCE

AI ยังเป็นการประเมินชุดการ์ดในมือปัจจุบันและคุณค่าสมุนระยะสั้น ไม่ได้วางแผนอนาคตแบบสมบูรณ์ ผลบอตใช้ค้นกำแพงความยากและข้อผิดพลาด; การเล่นบนโทรศัพท์ยังต้องประเมินความอ่านง่าย ความสนุกของแต่ละ build และเวลาที่ใช้ต่อคืน โดยเฉพาะการรับมือชาร์จ/สมุนเมื่อไม่รู้การ์ดในมือผี
