## 0. กติกาการทำงานกับเจ้าของเกม (ห้ามข้าม)

1. **คุยออกแบบก่อนแก้โค้ด** — การเสนอไอเดียใหม่ไม่ใช่การอนุญาตให้ลงมือ ต้องได้คำตอบตกลงก่อน
2. **ตกลงแล้วแต่ยังไม่ทำ → ลง backlog ก่อน** ไม่ใส่โค้ดทันที
3. ข้อความในเกม (การ์ด/ผี/เหตุการณ์) เป็นภาษาไทย ชื่อในโค้ดเป็นภาษาอังกฤษ
4. ตัวเลขบาลานซ์อยู่ใน `src/core/balance/notfm.ts` เท่านั้น ห้าม hardcode ใน component/reducer
5. ไม่ merge เข้า `main` ไม่ force push

## 1. ทิศทางหลักของเกม

- เป้าหมายคือเล่นได้ "แบบ Night of the Full Moon (Classic)" ด้วยธีมผีไทย — ยืม **วงจรการตัดสินใจ** ไม่ยืมตัวเลข/การ์ด: เห็น 3 ทางเลือก → ชั่งความเสี่ยง → สู้แบบอ่านเกมได้ → รางวัลเปลี่ยนเด็ค → ผลสะสมต่อรัน
- **ตัดออกแล้วโดยตั้งใจ — ห้ามเอากลับ:** ระบบคอมโบแบบตามลำดับการ์ด, มินเนียน, แท่นหลอมรวม (fusion altar), เซฟรุ่นเก่า
- ความลึกมาจาก: Prayer, Counter, Equipment, การยืมการ์ดผี (คนทรง), Curse และ synergy ธรรมชาติ
- 4 อาชีพต้องต่างกันที่ **กฎ/ทรัพยากร** ไม่ใช่แค่ตัวเลข: นักรบ = อุปกรณ์/เกราะ, หมอผี = Mana/คาถา, แม่ชี = บทสวดรอผล, คนทรง = ยืมการ์ดผี
- ความยากเพิ่มทีละ "กฎ" ไม่ใช่บวกเลือดอย่างเดียว
- **เวลารัน 60 นาทีไม่ใช่เพดาน** ตัวจับเวลาเก็บไว้ใช้วินิจฉัย; เกณฑ์จริงคือทุกหน้าต้องมีการตัดสินใจ (ถ้าหน้าไหนกดผ่านโดยไม่คิด ให้พิจารณาตัด/รวม) แนวทางคร่าว ๆ คือราว 20–30 นาทีต่อคืน

## 2. การตัดสินใจหลัง audit PR #15 และเหตุผล

### 2.1 พรแลกเปลี่ยนห้ามซ้อนกฎเดียวกัน
- **ปัญหา:** พรเหตุการณ์ "คำสัตย์ระฆัง" + แพนโดรา "คำสัตย์ยาวนาน" ต่างให้บทสวด +1 แต้ม ถ้าได้ทั้งคู่ บทสวด (1 แต้ม) กลายเป็น 3 แต้ม แต่ได้ 2 แต้ม/เทิร์น → แม่ชีเล่นการ์ดหลักของตัวเองไม่ได้
- **หลักที่ตั้ง:** พรที่มี `rules` (พรแลกเปลี่ยน) จะไม่ถูกเสนอ/เลือกได้ ถ้าผู้เล่นถือพรที่แก้กฎตัวเดียวกันอยู่แล้ว
- **ทำที่:** `bargainConflicts` (`src/core/cards/passives.ts`) ใช้ใน `rollTwoBlessings` (`src/core/level.ts`) และ `choiceLocked` (`src/core/events/story.ts`) + เพดานรวม `BARGAIN_RULE_LIMITS` ใน `balance/notfm.ts` กันเซฟเก่า
- **ถ้าจะเพิ่มพรแลกเปลี่ยนใหม่:** ใส่ key ใหม่ใน `BlessingDef.rules` และกำหนดเพดานใน `BARGAIN_RULE_LIMITS` เสมอ

### 2.2 Milestone ต้อง "เพิ่ม" ทางเลือก ไม่ใช่ล็อกของเดิม
- **ปัญหา:** Phase 7 เดิมล็อกการ์ดอาชีพที่มีอยู่แล้ว 16 ใบ (`unlockAt`) จนกว่าจะผ่านระดับ 1–4 ผู้เล่นใหม่จึงมีการ์ดให้เลือกน้อยกว่า Phase 6
- **ตัดสินใจ:** ถอด `unlockAt` ออกจากการ์ดเดิมทั้งหมด ระบบ `unlockAt`/`milestoneLevel` ยังอยู่ (ไว้ใช้กับ **การ์ดใหม่** ในอนาคต) หน้าบันทึกซ่อนส่วน "รางวัลระดับ 1–4" เมื่อยังไม่มีการ์ด milestone
- **Backlog:** ออกแบบการ์ด milestone ใหม่อาชีพละ 4 ใบ (ต้องคุยดีไซน์ + ภาพก่อน)
- เทสต์: `no existing card is milestone-gated` ใน `test/phase7.test.ts` จะล้มถ้ามีคนล็อกการ์ดเดิมอีก

### 2.3 ระดับ 4 เพิ่มกฎ "ผีโกรธเร็วขึ้น 1 เทิร์น"
- **ปัญหา:** กฎระดับ 4 เดิม (ร้านแพง 25% + ฟื้นเลือดครึ่ง) แทบไม่เปลี่ยนการต่อสู้ ซิมจึงออกมาว่าระดับ 4 ง่ายกว่าระดับ 3 ใน 3 อาชีพ
- **ตัดสินใจ:** ระดับ 4+ rage เริ่มเทิร์นผีที่ 2 แทน 3 (`DIFFICULTY.rageEarlyFrom/rageEarlyBy`) — เป็นแรงกดดันเชิงกฎ (ลงโทษไฟต์ยืด) ไม่ใช่บวกเลือด ตรงหลักข้อ 1
- จุดเดียวที่คำนวณ: `rageStartTurn()` ใน `src/core/campaign/nights.ts` (HUD ใช้ฟังก์ชันเดียวกัน)

### 2.4 เป้าบาลานซ์ (สำหรับบอท tactical, ไม่ใช่คนจริง)
| ระดับ | เป้าอัตราชนะรวม | ผล audit ก่อนปรับมือ (40 รัน/ช่อง) |
|---|---|---|
| 1 | ≥ 90% | 96% |
| 2 | 80–90% | 85% |
| 3 | 70–85% | 78% |
| 4 | 55–70% | 63% |
| 5 | 25–40% | 36% |

- แต่ละอาชีพในระดับเดียวกันห่างกันไม่ควรเกิน ~15–20 จุด และอัตราชนะของอาชีพเดียวกันควรลดลงตามระดับ (ต่างกันไม่กี่จุดถือเป็น noise ของซิม 40 รัน ±7%)
- **แม่ชี** ตั้งใจให้ "เริ่มช้า แข็งปลายรัน" (แพ้คืนแรกบ่อยกว่า แต่ระดับ 5 ชนะสูงสุด) — ลองเพิ่ม HP 60/ลด heal เป็น 2 แล้วผลแทบไม่เปลี่ยน จึงไม่แก้ รอทดสอบเล่นจริง

**ผล audit ด้านบนเป็นโค้ดก่อนปรับมือรอบ playtest** ผลใหม่ 400 รันอยู่ใน handoff: ระดับ 1–5 ชนะ 92.5 / 87.5 / 56.25 / 35 / 10% ไม่มี stalls แต่ระดับ 3–5 ต่ำกว่าเป้า จึงยังไม่ผ่านการรับรองบาลานซ์

## 3. งานที่ลงโค้ดแล้วและ backlog ที่เกี่ยวข้อง
- **ขนาดมือ / จั่ว แบบ NOTFM** — ลงโค้ดรอบ playtest #16 แล้ว (game source `1f7cd983`; CI 38380455411 ผ่าน verify/android/native; APK 1.0.42/code43)
  - คงมือสูงสุดท้ายเทิร์น (`retain`) กับจั่วต่อเทิร์น (`drawPerTurn`) แยกกัน เริ่ม 2 ทั้งคู่ในรันใหม่; มือเปิดศึกตามมือที่พัฒนาแล้วและคงตัวปรับ openingDraw
  - เอา retain/draw ออกจากการสุ่มรางวัลเลเวลปกติ เพิ่มผ่านตัวเลือกรางวัลบอสคืน 1–2 แทนการ์ด หรือพรแพนโดราหายาก เพดาน 4; ไม่ใช้การเติมให้เต็มมือทุกเทิร์น
  - UI แสดงมือ/จั่วแยกชัด รวมรายละเอียดในมือจริง เพดานระหว่างเล่น และกองจั่ว/ทิ้ง
  - มือแบไม่หวง +1 มือ/เปิดศึก; ธูปหลุดมือยังลดการเก็บท้ายเทิร์น; หนี้เหรียญศาล/ศาลเหล็กยังลดมือเปิดศึก; ระดับ 5 ลดจั่วคืน 3 แต่ไม่ต่ำกว่า 2 สำหรับรันใหม่ และไม่เพิ่มค่าจั่วเดิมที่ต่ำกว่า floor
  - ซิมใหม่ 400 รันไม่มี stalls แต่ระดับ 3–5 ต่ำกว่าเป้าบอทเดิม — **ยังไม่ผ่านการรับรองบาลานซ์** ดู `docs/playtest-2026-10-13/balance-summary.json` และ handoff; ต้องจูน/เล่นจริงต่อ ไม่ใช้ผลเก่ารับรองโค้ดใหม่
- การ์ด milestone ใหม่ (ข้อ 2.2)
- Tutorial สั้นตอนพบกติกาครั้งแรก (G11)
- Talent tree / Nightmare modifiers — optional หลังจูนระดับ 1–5 จากการเล่นจริง
- เพิ่มทรัพยากร Mana/Prayer/Counter ให้ผีบางตัว — เฉพาะผีที่ identity เหมาะ
- ทดสอบเล่นจริงบน Android: ความรู้สึกของ build อุปกรณ์/บทสวด/ยืม, ระดับ 5, และเวลาต่อคืน
