## แก้จากรีวิว main (ทำไปพร้อมกัน)
- เอาการ์ดทดสอบ "พระประธาน" ออกจากสมุดสะสม (โค้ดแจกการ์ดยังทำงานเฉพาะ APK ทดสอบที่ตั้ง `EXPO_PUBLIC_TEST_WIN_CARD=1`)
- ร้าน/รางวัล/เลเวลอัปไม่สุ่มการ์ดใช้มานาให้อาชีพที่ไม่มีแหล่งมานา (`pack.ts` `fitsClass`)
- **รางวัลการ์ดหลังผีดุ/บอสสุ่มความหายากตามคืน** (`ECONOMY.rewardRarity`) — เดิมเงื่อนไขนับไฟต์ (<3, <7) ไม่เคยทำงาน รางวัลแรกคือบอสคืน 1 ที่ไฟต์ 8 จึงมี Legendary ราวครึ่งหนึ่งของรางวัลทั้งหมดตั้งแต่บอสแรก ขัดกับ T6
- พรแพนโดราไม่ข้ามเพดานแต้ม 3 / ช่องอุปกรณ์ 3 อีก (เดิมได้แต้ม 4 และช่องที่ 4 ซึ่งเลื่อนไว้)
- มือเปิดศึกคิดจากมือสูงสุดหลังหักพร (ธูปหลุดมือ)
- เทสต์สีที่แดงบน main: ย้ายสีเข้า token ใน `app/theme.ts`
- **CI บน main พังอยู่แล้วแต่ไม่มีใครเห็น** (merge v1.0.48 ติด `[skip ci]`): ชั้นแสงเทียนของเพจ (v1.0.48) มี test id ขึ้นต้นด้วย `adventure-frame-` เหมือนตัวเพจ เช็กบนมือถือจึงวัดความทึบของแสงที่จางเป็น 0 แล้วตก → เปลี่ยนเป็น `adventure-glow-*` · และเพจที่เปิดเผยแล้วจะไม่เล่นเฟดซ้ำเมื่อกลับจากไฟต์หรือปิดกระเป๋า (เฟดเฉพาะเพจที่เพิ่งแจกใหม่) ตามที่เช็กเดิมกำหนด · รันเช็กมือถือ 44 ข้อผ่านในเครื่องด้วย Chromium จาก npm (`@sparticuz/chromium`)

## หลังเล่นจริงครั้งแรก (15 ต.ค. 2026)
- เจ้าของเล่นนักมวย: ระบบใหม่โอเค ผีเริ่มเก็บการ์ด สนุกขึ้น
- แก้: นักมวย/แม่ชี (ไม่มีมานา) ไม่เห็นพรที่ได้แค่มานา (พลังวิญญาณ, พลังหายนะ) หรือพรที่ทำงานกับการ์ดที่อาชีพไม่มี (โล่พิธีกรรม: คาถา) และไม่เห็นเลเวลอัป "มานาตั้งต้น" (`pack.ts` `blessingFitsClass`, `classUsesMana`)
- เจ้าของสั่ง **ไม่ต้องรองรับเซฟเก่า**: ลบการ์ดอาวุธเก่า 8 ใบ (และภาพที่ไม่มีใครใช้) ออกจากเกมทั้งหมด
- ข้อสังเกตต่อ: ผีท้ายคืนเลือดยังต่ำ ชนะง่าย → ข้อเสนอ "ความลึกตามไฟต์ที่เท่าไรของคืน" รอเจ้าของเลือก

อ่านผล:
- **นักมวยอยู่ในเป้า** ระดับ 2–5 และต่ำกว่าเป้าเล็กน้อยที่ระดับ 1 (85%) ระดับ 4–5 แพ้คืน 1 กับบอสเก็บหัว (night-head-collector) เป็นหลัก ซึ่งเป็นแรงกดดันที่ตั้งใจไว้
- **อาชีพอื่นลดลง** โดยเฉพาะหมอผี (ระดับ 3: 70→50%) สาเหตุหลักคือแก้รางวัล Legendary (เดิมแจก Legendary เยอะเกินจนช่วยทุกอาชีพ) ไม่ได้แก้การ์ดอาชีพอื่น — ยอมรับไว้เพราะทุกอาชีพจะได้ชุดการ์ดใหม่ตามแนวนักมวย ถ้าต้องการปล่อย APK ให้คนเล่นอาชีพอื่นก่อน ปุ่มแรกคือ `ECONOMY.rewardRarity`
- บอทยังเล่นกลไกใหม่ได้ไม่เก่งเท่าคน (เช่น ไม่วางแผนเก็บการ์ดข้ามเทิร์นเพื่อต่อท่า) ตัวเลขจริงต้องเล่นบนมือถือ

## ยังไม่ได้ทำ / ขั้นต่อไป (เรียงลำดับ)
1. **ภาพ** — 37 ใบใหม่ + 4 ใบที่ภาพเดิมไม่เข้าธีม (ยันต์รับแล้วสวน/ตั้งการ์ดสวนหมัด/ศอกตัดกรรม/แม่ไม้ครูห้าคืน มีดาบ โล่ หรือประตูวัด) + ศิษย์ค่าย 6 ตัวบนสนาม → `docs/nak-muay/ART-PROMPTS.md` ใส่ภาพแล้วเพิ่มใน `app/cardArt.ts` และลบ id ออกจาก `art-prompts.json`
2. **UI ไฟต์** — ตอนนี้แสดงจังหวะ ยก สวน ศิษย์ค่าย ช้ำ/มึน ผ่านแถบสถานะเดิม (ใช้ได้ แต่ยังไม่สวย) ที่ต้องทำ: มาตรจังหวะ 0–8 ข้างมือการ์ด, ไอคอนท่าที่มุมการ์ด, ตัวละครศิษย์ค่ายยืนข้างผู้เล่น (ใช้ภาพ `assets/minions/`), ลูกสมุนผีข้างผี, แอนิเมชันตอนสวน/พักยก — ทำ mockup ให้เจ้าของดูก่อนลงโค้ดหน้าจอ
3. **ผีคืน 1 + บอสคืน 1 ชุดใหม่** — ผีแต่ละตัวมีกลไกเด่น 1 อย่าง + การ์ดประจำตัว 3–4 ใบ, บอสใช้ลูกสมุน/มึน/สวนของฝั่งผี เอนจินมินเนียนฝั่งผีพร้อมแล้ว (`summon`, `act`, `taunt`, `turns`, `sweep`)
4. **AI ผีเก็บไพ่** — ตอนนี้การ์ดโจมตีผีฟรีและ AI เล่นทุกใบ ผีจึงเก็บไพ่แค่ 2–9% ของเทิร์น ต้องให้ AI รู้จักเก็บไว้ชาร์จ/คอมโบ และไม่ตีใส่เกราะที่ตั้งสวนไว้
5. **ผูกยกกับผีโกรธ** — ตอนนี้ยกแยกจากผีโกรธ (โกรธยังเริ่มที่เทิร์นผีที่ 3/2 ตามระดับ) แนวที่ตกลงไว้คือใช้ตัวนับเดียว "เข้ายก 2 ผีเริ่มโกรธ" ต้องซิมก่อนเพราะเลื่อนโกรธ 1 เทิร์นกระทบทุกระดับ
6. **เล่นจริงบนมือถือ** แล้วจูนตัวเลขการ์ดนักมวย (`class_cards.json`) และ `FIGHTER_RULES`
7. อาชีพถัดไปตามแนวเดียวกัน (หมอผี / แม่ชี / คนทรง) — เจ้าของเลือกลำดับ
