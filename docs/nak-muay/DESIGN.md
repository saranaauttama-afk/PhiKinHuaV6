# นักมวยคาดเชือก — เอกสารออกแบบ (ลงโค้ดแล้ว 14 ต.ค. 2026)

อาชีพแรกของรอบ **"ขยายการ์ดให้เทียบ Night of the Full Moon"** แทนที่ "นักรบวัด" (`ClassId` ยังเป็น `warrior` เพื่อไม่ให้เซฟเก่าพัง)
Branch: `work/nak-muay` · สถานะงานและสิ่งที่ต้องทำต่อ: `docs/nak-muay/HANDOFF.md` · ภาพ: `docs/nak-muay/ART-PROMPTS.md`

## 0. ทำไมถึงเปลี่ยน (เจ้าของตัดสิน 14 ต.ค. 2026)

- เจ้าของเล่นแล้วรู้สึกว่า **การ์ดทั้งฝั่งเราและผียังน้อยและไม่หลากหลาย** เมื่อเทียบ NOTFM (ดูภาพสำรับที่เล่นจริงและหมวดการ์ด Action / ATK / Equipment / Mana / Prayer / Counter / Spell / Special)
- ตัวเลขยืนยัน (main @ d4f0d4f): นักรบวัดมีการ์ดอาชีพ 24 ใบ ส่วนใหญ่เป็น "ดาเมจ X / เกราะ X" ต่างกันแค่ตัวเลข · ผี 34 ตัว 352 ใบ แต่มีรูปแบบผลแค่ 24 แบบ (เกือบ 70% เป็นตี/ตีหลายครั้ง/เกราะ/เพิ่มพลัง)
- ความหลากหลายของ NOTFM มาจาก **จำนวนกลไก** ไม่ใช่จำนวนใบ — จึงสร้างกลไกใหม่ก่อน แล้วค่อยใส่การ์ด
- การตัดสินใจ: **เลื่อนขึ้นสโตร์** · **เอามินเนียนและคอมโบกลับมา** (ยกเลิกข้อห้ามใน `docs/phase7/DESIGN-DECISIONS.md` เฉพาะสองระบบนี้) · ทำเต็มที่ไม่กั๊ก · **โฟกัสทีละอาชีพ เริ่มนักมวย**
- เปลี่ยนชื่อเพราะ "นักรบวัด" ไม่มีอยู่จริง (พระจับอาวุธไม่ได้ วัดไม่มีนักรบประจำ) ที่ใกล้ที่สุดคือครูมวยที่ฝึกศิษย์ในลานวัด → เจ้าของเลือก **นักมวยคาดเชือก** (มวยโบราณพันมือด้วยเชือกดิบ)

## 1. หลักการออกแบบ

1. **ทุกใบต้องมีเหตุผลให้เลือกนอกจากตัวเลข** — มีท่า มีเงื่อนไขต่อจาก มีบทบาทในสายเด็ค
2. **มือเล็ก (2 ใบ) ต้องมีความหมายมากขึ้น ไม่น้อยลง** — จังหวะผูกกับการเลือกว่าจะเก็บใบไหนไว้ต่อท่าเทิร์นหน้า
3. **ผู้เล่นอ่านออกในไม่กี่วินาที** — กลไกทุกตัวแสดงบนแถบสถานะ (จังหวะ, ยก, สวน, ศิษย์ค่าย, ช้ำ/มึนบนผี)
4. **กลไกเดียวใช้ได้ทั้งสองฝั่ง** — มินเนียน สวน มึน ใช้กฎเดียวกันกับผี (ผีชุดใหม่จะใช้ต่อ)
5. **ตัวเลขอยู่ที่เดียว** — `src/core/balance/notfm.ts` (`FIGHTER_RULES`, `MINION_RULES`, `CLASS_PASSIVES.warrior`) และการ์ดใน `class_cards.json`
6. **ไม่มีอาวุธ** ดาบ หอก ขวาก ย้ายออก (เก็บไว้ให้อาชีพอนาคต) นักมวยใช้มือ เท้า เข่า ศอก + ของขลังแบบมวยไทย

## 3. สามสายเด็ค

1. **จังหวะรัว** — การ์ดถูก ท่าหลากหลาย เลี้ยงจังหวะให้สูงแล้วทุกหมัดหนักขึ้น (หมัดอัปเปอร์, เข่าสามชั้น, เงาซัดรัว, หนุมานถวายแหวน, คนเป่าปี่ชวา, มือกลองแขก, มงคล, ผ้าประเจียดครูให้)
2. **ทุบช้ำปิดท่าหนัก** — หมัด/เข่าเบาแปะช้ำ แล้วปิดด้วยศอก/เตะท่าหนัก (หมัดฮุกคู่, จ้องตาคู่ชก, จับคอขย่มเข่า, เตะเสยคาง, ศอกตัดกรรม, เชือกคาดเศษแก้ว)
3. **ตั้งการ์ดสวน + ค่ายมวย** — เกราะสูง ตั้งสวน ให้ศิษย์ค่ายช่วย (ตั้งการ์ดสวนหมัด, ยืนหยัดกลางเวที, กางเกงมวยลงยันต์, นักมวยรุ่นพี่, พี่เลี้ยงมุมเวที, ประเจียดแขน)

## 4. อาชีพ

- ชื่อ **นักมวยคาดเชือก** · ฉายา ผู้ต่อแม่ไม้ · เลือด 60 · มานา 0 (ร้าน/รางวัลไม่สุ่มการ์ดใช้มานาให้แล้ว)
- passive **แม่ไม้มวยไทย** = จังหวะ (แทน "ยืนเฝ้าประตู: สวมอุปกรณ์ได้เกราะ 3")
- สกิล: A **ครูต่อท่าให้** (เพิ่มดาวการ์ด 1 ใบ · เดิม "ลงยันต์อาวุธ" เปลี่ยนชื่อเพราะไม่มีอาวุธแล้ว) · B **ครูสอนมวย** · C **ใจเพชร** (ไม่เปลี่ยนผล)
- บทนำ: ตื่นจากเสื่อในค่ายมวยท้ายวัด พันเชือกดิบรอบมือ (แทน "หยิบดาบวัด")
