# 📖 Game Rules (Player Version)

## การไหลของเกม
- เริ่มที่แผนที่ (Map Page) มี Encounter 3 ช่อง
- เมื่อเลือก Encounter ใด ๆ และเล่นเสร็จ → Encounter ใหม่จะถูกสุ่มขึ้นมาแทน
- ทำซ้ำจนกว่าจะเจอ **Path Split** → จะเปลี่ยนหน้าใหม่ (Encounter 3 ช่องใหม่ทั้งหมด)
- แต่ละโซนจะจบด้วย **Boss** (กลาง/สุดท้าย)

## Encounter ที่พบได้
- **ศัตรูปกติ (Normal)**: ใช้การ์ดต่อสู้
- **ศัตรูพิเศษ (Elite)**: ยากขึ้น ได้รางวัลมากขึ้น
- **Boss กลาง/สุดท้าย**
- **Event**: เหตุการณ์สุ่ม (เลือกตอบ → ได้ผลลัพธ์)
- **ร้านค้า (Shop)**: ซื้อการ์ด/ของ

## ร้านค้า
- เข้าแล้วซื้อได้ → ออกจากร้านโดยไม่ซื้อ → ร้านยังอยู่
- ซื้อของจนหมด → ร้านหายไป
- ผู้เล่นสามารถ “ลบร้าน” ออกจากแผนที่ได้เอง
- ร้านเดิมอาจกลับมาเจออีกในหน้าถัดไป

## การเลื่อนหน้า (Pages)
- เล่น Encounter ไปเรื่อย ๆ → เมื่อถึง **ทางแยก (Path Split)** จะเปลี่ยนไปหน้าใหม่
- แต่ละโซนจะมี Boss ใหญ่เป็นจุดจบ
