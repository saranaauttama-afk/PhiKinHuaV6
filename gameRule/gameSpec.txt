Game Design Spec – ผีไทย Deck-Builder (สไตล์ Night of the Full Moon)
🎯 Concept Overview

แนวทาง: Deck-builder, Roguelike Adventure

Theme: ผีไทย (Slime → กุมารทอง, Wolf → ผีกระสือ ฯลฯ)

โครงสร้างรัน:

Part 1: 7 fights → fight #7 = Mid Boss

Part 2: 7 fights → fight #15 = Final Boss

Secret Boss: ต่อท้าย Final Boss ถ้ามีเงื่อนไข

รวมทั้งเกม = 15 fights (แน่นอน, fixed length)

🗺️ Map & Page System

Page = 3 slots (encounter offers)

EncounterKinds: combat, elite, event, shop, next_event, boss, secret_boss

Mechanics:

เมื่อเลือก & จบ encounter (ถ้าไม่ใช่ boss/next_event) → refresh ช่องนั้นทันที ด้วย encounter ใหม่ (Dynamic Refresh)

Force Split: ถ้า encounter ที่เคลียร์สะสมเกิน quota → ช่องถัดไปกลายเป็น next_event → บังคับเปลี่ยนหน้า

Boss: ถูกล็อกที่ fight index (7 = Mid, 15 = Final)

### Fight Progression Logic (IMPLEMENTED ✅)
- Fight 1-2: T1-T2 random (60% T1, 40% T2)
- Fight 3-4: T1-T3 + Elite 5% chance
- Fight 5-6: T2-T3 + Elite 10% chance  
- Fight 7: Mid Boss (fixed)
- Fight 8-9: T3-T4 + Elite 15% chance
- Fight 10-12: T4-T5 + Elite 20-25% chance
- Fight 13-14: T5 + Elite 25-30% chance
- Fight 15: Final Boss (fixed)
- Fight 16+: Secret Boss (optional)

### Key Features (IMPLEMENTED ✅)
1. **Deterministic Selection**: ผีถูกเลือกตั้งแต่ map generation แล้วแสดงชื่อให้เห็น
2. **Thai Theme**: ใช้ชื่อผีไทยแทน generic monsters
3. **Boss Visual**: กรอบสีแดงและเตือนก่อนเจอบอส
4. **Fight Counter**: แสดงความคืบหน้า (X/15) และเตือนบอส
5. **Anti-Duplicate per Tier**: แต่ละ tier ที่โหลดมาในหน้าเดียวกันต้องไม่ซ้ำกัน (ใช้ pool ที่หลากหลาย)

🎲 Encounter Generation Algorithm
interface EncounterOffer {
  kind: 'combat'|'elite'|'event'|'shop'|'boss';
  enemyId?: string;   // กรณี combat
  tier?: string;
  groupSize?: number;
  level?: number;
}

function generateCombatOffer(args: {
  fightIndex: number;
  part: 1|2;
  rng: () => number;
}): EncounterOffer {
  // 1) เลือก tier ตาม fightIndex (ดูตาราง)
  const tier = pickTierForFight(args.fightIndex, args.part, args.rng);

  // 2) เลือก enemy จริงจาก pool
  const pool = ENEMY_POOLS[tier];
  const enemyId = pool[Math.floor(args.rng() * pool.length)];

  // 3) group size & level range
  const groupSize = rollGroupSize(tier, args.fightIndex, args.rng);
  const level = rollLevel(tier, args.fightIndex, args.rng);

  return { kind: 'combat', enemyId, tier, groupSize, level };
}

Gold & Rewards
// Base rewards per enemy
const BASE_EXP_PER_ENEMY = { T1:4, T2:6, T3:8, T4:10, T5:12, Elite:18 };
const BASE_GOLD_PER_ENEMY= { T1:3, T2:4, T3:5, T4:6, T5:7, Elite:10 };

// Part multipliers
const PART_MUL = { 1: 1.0, 2: 1.25 };

// Depth multipliers
const DEPTH_MUL = { early: 1.0, mid: 1.1, late: 1.2 };

// Boss rewards
const BOSS_REWARDS = {
  mid:   { exp: 80,  gold: 60  },
  final: { exp: 120, gold: 100 },
  secret:{ exp: 160, gold: 140 },
};

function rewardForFight({tier, part, depth, groupSize}) {
  const exp = Math.floor(BASE_EXP_PER_ENEMY[tier] * PART_MUL[part] * DEPTH_MUL[depth] * groupSize);
  const gold= Math.floor(BASE_GOLD_PER_ENEMY[tier]* PART_MUL[part] * DEPTH_MUL[depth] * groupSize);
  return { exp, gold };
}
